# Jetson 개발 환경과 재현 조건

> 기록 기준: 2026-10-26  
> 대상: Fast-SCNN 분할 모델의 ONNX 변환, TensorRT 추론 및 RGB-D 코스트맵 실험

## 이 문서의 목적

이 문서는 모델 성능을 해석하기 전에 **어떤 하드웨어·라이브러리 환경에서 결과를 얻었는지** 확인하기 위한 기록입니다. Fast-SCNN을 학습한 뒤 ONNX로 내보내고, TensorRT 엔진을 생성해 Jetson GPU에서 추론하는 과정에 사용한 주요 버전을 정리했습니다.

측정 결과를 재현할 때는 라이브러리 버전뿐 아니라 **엔진 정밀도, 빌드 옵션, 전력 모드와 클럭 설정**도 함께 확인해야 합니다. 이 설정은 각 실험 문서에 별도로 기록합니다.

## 확인된 개발 환경

| 구성요소 | 기록된 버전 |
|---|---|
| NVIDIA L4T | 39.2.1 |
| CUDA Toolkit | 13.2 (V13.2.86) |
| cuDNN | 9.20.0.46 |
| TensorRT 및 Python 바인딩 | 10.16.2.10 |
| PyTorch | 2.12.0+cu132 |
| ONNX | 1.23.2 |

위 표는 **2026-10-26에 확인한 목록**입니다. 이후 실험의 Python·NumPy·OpenCV 등 세부 버전은 각 측정 문서에 기록된 값을 기준으로 합니다.

## 이 환경에서 수행하는 작업

Fast-SCNN 모델을 ONNX로 변환하고 TensorRT FP32·FP16 엔진을 구성했습니다. 이 엔진을 사용해 Jetson GPU 추론 성능과 정확도, 메모리 사용량을 비교하며, RealSense RGB-D 데이터에서 장애물을 분할하고 로컬 코스트맵을 만드는 앱도 실행합니다.

## 추가로 확인해야 할 항목

현재 이 문서의 2026-10-26 기록에는 다음 항목의 확인 결과가 들어 있지 않습니다.

- Python 버전
- Ubuntu 및 JetPack 버전
- PyTorch에서 CUDA를 사용할 수 있는지 여부
- 실제 가상환경에서 TensorRT Python 모듈을 불러올 수 있는지 여부

따라서 위 항목은 확인된 사실처럼 적지 않았습니다. 패키지 목록은 `requirements-jetson.txt`에, 시스템 라이브러리 버전은 이 문서에, 엔진의 정밀도 및 빌드 옵션은 각 엔진의 실험 기록에 남겨 관리합니다.
